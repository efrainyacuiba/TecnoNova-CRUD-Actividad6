# Importante: la vista previa en /docs era la versión ANTERIOR

El nuevo frontend cinematográfico de Figma Make está integrado en las vistas Razor de ASP.NET Core (`Views/Interfaz`) y se muestra con `dotnet run` + PostgreSQL.

**No** uses `docs/index.html` para evaluar el nuevo diseño: es la demo anterior y no contiene el procesador 3D de Figma.

Si quieres ver la demo original hecha en Figma Make, abre el archivo Figma Make en su navegador o ejecuta el proyecto React exportado (no es el CRUD real).
